ECCHOS OF THE PAST -- VERSION LOG
==================================
Keep this file updated each time you make changes and upload a new
release to Play Console. Match the version number here to the
"Release name" you type into Play Console so you can always tell
what's actually live.

HOW TO USE THIS FILE
---------------------
1. Before you generate a new .aab in PWABuilder, add a new entry
   below with today's date and a short list of what changed.
2. Use that same short list as your Play Console release notes.
3. Bump the version number (v1.0 -> v1.1 -> v1.2 etc.) -- small
   number for small changes, bigger jump for major changes.

==================================

v1.0 -- Initial build
- First working version of the app, built as "Spectratalk"
- Core tools: Spirit Box, EMF Meter, Ghost Radar, EVP Recorder,
  Infrared Camera

v1.1 -- Branding
- App icon created (ghost design on dark background)
- Icon updated to custom "Ecchos of the Past" artwork with
  gold/black bordered title text

v1.2 -- Rename
- Renamed app throughout (manifest, page title, internal IDs,
  exported file names) from "Spectratalk" to "Ecchos of the Past"

v1.3 -- Pro removal, multiplayer removal, polish
- Removed the Pro/paywall system -- all features now free
- Removed the multiplayer "Shared Session" feature entirely
- Added screen wake lock (phone won't sleep while app is open)
- Confirmed disclaimer/agreement screen at app start (entertainment
  only, use-at-own-risk, no liability -- already existed, just
  renamed inside it)
- Made Spirit Box more realistic: added radio frequency "chirp"
  sound during scanning and when a question is asked

v1.4 -- Session history persistence
- Spirit Box conversation transcript now saves and reloads
- Investigation Timeline (cross-tool activity log) now saves
- Camera evidence gallery (captured photos + AI captions) now
  saves and reloads

v1.5 -- EVP save prompt
- EVP recordings now show a "Save to device?" prompt after each
  recording, with a storage-space warning
- Only saves the actual audio file if you tap "Save to Device"
- Capped at the 8 most recent saved recordings to protect storage

v1.6 -- EMF/Activity gauge realism
- The EMF needle and Spirit Activity gauge now drift smoothly and
  continuously instead of jumping to a new number every ~2 seconds
- Spike detection, temperature drift, and pattern-correlation logic
  still run on the original slower timing so spikes aren't logged
  or flashed dozens of times in a row while the needle glides
  through a high reading

v1.7 -- Radar/Camera realism, notes, cleanup
- Ghost Radar blips now fade in gradually and drift slightly during
  their lifetime instead of popping in and staying pinned in place
- Infrared Camera feed now has constantly-shifting sensor grain/noise
  layered into every frame, like real low-light footage
- Added an Investigator Notes field on the profile screen (free
  text, saves automatically, persists between sessions)
- Removed leftover "PRO status" wording from the backup description
  and an unused empty ad-banner slot left over from the old
  monetization system
- Found and fixed 4 more places where the old app name ("Echoes of
  What Was" / "ECHOES OF WHAT WAS") was still hardcoded -- including
  inside the Share Highlight Reel feature, which turned out to
  already exist and work (generates a shareable session-stats image
  via the native share sheet)
- Confirmed the EVP Recorder's live waveform + spectrogram were
  already implemented using real microphone data (no changes needed)

v1.8 -- Camera flash fix
- The Camera screen's FLASH button now actually turns on the
  device's real torch/flashlight when the phone/browser supports
  it (was previously just a cosmetic on/off toggle with no real
  effect)
- Falls back to a visual-only indicator with a logged note if the
  device or browser doesn't expose torch control
- Torch now automatically turns off when the camera is disabled,
  so it can't get stuck on in the background

v1.9 -- Real theme system (8 themes)
- Themes now actually change the app's real background/panel
  colours everywhere, not just accent highlights like before
- Added 8 full themes with distinct colour palettes AND restyled
  buttons/borders per theme: Haunted Hotel, Vampire Castle,
  Witch's Cottage, Cursed Carnival, Ghost Ship, Victorian Manor,
  Abandoned Asylum, Zombie Laboratory
- Each theme has its own button shape/border/press-glow style
  (e.g. Cursed Carnival buttons jitter on press, Abandoned Asylum
  buttons flicker like failing fluorescent lights)
- Settings screen now shows the selected theme's name below the
  swatches
- Old flat accent colours (Green, Purple, Red, Cyan, Amber, Pink,
  Dynamic) still work exactly as before
- Full design spec for these 8 themes (colour palette, UI style,
  per-screen art direction, sound ideas) written up in
  SpectraTalk_Theme_Design_Bible.docx -- 42 more themes are
  planned/named but not yet designed or built

v1.13 -- Theme lock system

  locked -- shown greyed out with a padlock icon in Settings,
  tapping one shows "coming soon" instead of switching to it
- The original 7 free themes (Dynamic, Green, Purple, Red, Cyan,
  Amber, Pink) are unaffected and work exactly as before
- To release a theme for real later: open index.html, find that
  theme's entry in THEME_PRESETS, and change locked:true to
  locked:false (or delete that part entirely) -- nothing else
  needs to change
- No payment/purchase system built yet -- this is just the
  lock/reveal mechanism. Actual selling (Play Console in-app

  work whenever you're ready for it

v1.15 -- Developer unlock for testing locked themes
- Tap the theme name label under the theme swatches 7 times
  (same pattern as Android's own "tap build number 7 times" dev
  unlock) to toggle full access to every locked theme on that
  device only
- This is per-device, stored locally -- doesn't affect testers or
  anyone else's copy of the app, and doesn't touch the actual
  locked:true flags in the code
- Tap it again 7 times to turn dev mode back off (locks
  everything again for that device)
- Lets you preview/QA every theme as it's built without waiting
  for the real purchase system
